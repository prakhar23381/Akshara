## Reference Decisions

### [2026-07-05] Automated Sequential Assortment Game Flow
* **Context:** The student should not have to manually choose between activities. Every letter play session should automatically run through the three games.
* **Decision:** Formed a direct linear navigation flow: `/animation` → `/pronunciation` → `/example-words` → `/tracing` → `/memory` → `/game` → `/reward` → `/roadmap`.

### [2026-07-05] Dynamic Student-Specific similarity card matching
* **Context:** The card flip game should match letters against visually similar counterparts rather than words, and dynamically customize the index depending on what letters the student confuses in practice.
* **Decision:** Matches identical letters (e.g. `भ` vs `भ`). Pulls the student's actual history from `fetchProgressReport().letter_stats[target].confused_with` to customize card distractors, falling back to a static visual similarity index map. Mismatches reset card flip states to fold them back face-down.

### [2026-07-05] Dotless Tracing Canvas & Drawing Score check
* **Context:** Visual dots and magnetic lassoing distract children and decrease tracing accuracy. A clearing tool and score checking are required immediately after tracing.
* **Decision:** Enlarge interaction canvas to 500x500 while scaling input coordinates back to 400x400 source space. Remove visual yellow/green dots. Sample path at spacing = 10 for precision, and provide "Clear Canvas" and "Check Drawing" controls with success/try again card overlays.
