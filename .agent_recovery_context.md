## 4. Reference Decisions  *(append-only — never prune)*

### [2026-10-07] Three-file bookkeeping convention
* **Context:** Six overlapping tracking files had accumulated, two of them
  actively misleading. The recovery context pointed at three files that no longer
  existed, so trusting it sent work at dead code.
* **Decision:** `TODO.md` holds outstanding work only. This file is live working
  memory, pruned whenever something closes. `STATUS_LOG.md` is the permanent
  record, so pruning never loses history. Completed items move out of `TODO.md`
  into the log, with a condensed line here only while it still aids recovery.

### [2026-10-07] Structure cleanup scope, C0–C6
* **Context:** Full-tree diagnosis found 48 dead UI files, 51 unreachable
  dependencies, duplicated secrets in `.bak` files, three copies of one audio
  script, an empty `ml/`, a broken 231 MB venv, and docs contradicting the code.
* **Decisions:** (1) Commit the refactor first as a safety point, so every later
  deletion is revertable. (2) Delete all 48 UI files and prune all 51
  dependencies — re-adding a component later is one shadcn CLI command.
  (3) Rewrite the four docs that make false claims rather than banner them.
  (4) Commit `.legacy/` now and delete it only after V1–V4 pass, since its 11
  screens carry L1–L8 fixes that exist in no commit.
* **Trade-off accepted:** the `Akshara/Akshara` nesting stays. Flattening costs
  a Vercel project change and every config path, and buys only tidiness.

### [2026-07-05] Automated sequential game flow
* **Context:** The student should not have to choose between activities.
* **Decision:** One linear flow per letter. *Superseded in form by P3 — the
  navigation is now a step machine at `/play` derived from `levelConfig`, not a
  chain of `navigate()` calls — but the pedagogical intent still holds.*

### [2026-07-05] Student-specific similarity card matching
* **Context:** The card game should match visually similar letters, customised
  to what each student actually confuses.
* **Decision:** Match identical glyphs (`भ` vs `भ`), pulling distractors from the
  student's own `confused_with` history and falling back to a static visual
  similarity index.

### [2026-07-05] Dotless tracing canvas and scored drawing
* **Context:** Visual dots and magnetic lassoing distract children and inflate
  accuracy.
* **Decision:** No guide dots. Sample the path at spacing 10, score by grid-based
  Jaccard similarity so a wrong character or a scribble cannot pass, and offer
  "Clear Canvas" and "Check Drawing".

### [2026-10-06] Session and reporting defaults
* Tracing appears only when `levelConfig.input_mode === "trace"`, matching
  `STATE_RULES`, rather than in every session.
* A stale session resumes if under 6h old, else is marked `abandoned`.
* Abandoned sessions appear in the report but are excluded from accuracy
  aggregates — drop-off is a signal and should not dilute the figures.
* `/report` stays behind the parent math gate.
* "Download" is print-to-PDF; no new dependency unless a real `.pdf` is needed.
* Error magnitude stays single-hue by bar length — no red/amber/green, because
  there are no validated cut-off scores.

### [2026-10-07] Cleanup kept behaviour-neutral
* **Context:** a fresh `npm install` after pruning 50 dependencies floated the
  caret ranges, taking `@supabase/supabase-js` from 2.105.1 to 2.117.2 and
  adding 21 KB of JS.
* **Decision:** pin both drifted packages to the versions the previous lockfile
  had installed, so the cleanup carries no library upgrade. The two
  high-severity advisories found at the same time (`react-router`, `vite`) are
  logged as TODO B1 rather than fixed in a cleanup commit, because both fixes
  are outside the stated ranges.
* **Trade-off accepted:** the project sits on known-vulnerable `react-router`
  until B1 is decided. Most of the 12 advisories are SSR/RSC paths this SPA does
  not take; the `<Link>`/`useNavigate` open redirect is the one that applies.

### [2026-10-07] Agent config stays split, deliberately
* **Context:** `.agents/` and `.claude/` both sat outside the repo, so a clone
  got neither and `akshara2.md` was one `rm` from unrecoverable. But Claude Code
  is launched from the parent folder, which is where it looks for settings,
  permissions and agent definitions.
* **Decision:** move `.agents/rules/` into the repo so the rules are versioned
  with the code; leave `.claude/` in the parent folder so discovery keeps
  working. `.claude/agents/akshara.md` is therefore a local, unversioned file.
* **Trade-off accepted:** the agent definition is not in git. The alternative —
  a copy in each place — is exactly what produced the `custom_agent.md`
  divergence this cleanup removed. Reversible in one `git mv` if the session
  root ever becomes the repo.
* **Risk flagged:** if another editor reads `.agents/rules/` from the parent
  folder, moving it will have stopped that rule from loading. One `git mv` back.
