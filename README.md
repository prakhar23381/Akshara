# Akshara-Flow

Akshara-Flow is a React-based web application with a modern tech stack (Vite + React). The original wireframe is available at [Figma](https://www.figma.com/design/98d7No2R8bDi7VNi4IHfKT/Wireframe-for-Akshara-Flow).

## Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repository and navigate to the project root.
2. Install the dependencies:
   ```bash
   npm install
   ```

### Development Server

Start the development server:
```bash
npm run dev
```

### Build for Production

To build the application for production:
```bash
npm run build
```
